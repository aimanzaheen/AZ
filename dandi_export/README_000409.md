# DANDI:000409 export (IBL Brain Wide Map)

Plain-table export of
[DANDI:000409 v0.260309.1324](https://dandiarchive.org/dandiset/000409/0.260309.1324),
the International Brain Laboratory Brain Wide Map: Neuropixels recordings
across hundreds of Allen CCF regions in mice performing the IBL decision-making
task, with block-wise stimulus priors.

The Dandiset is ~50 TB, but ~43 TB of that is raw voltage and ~5 TB is video.
`export_000409.py` uses only the 459 `desc-processed_behavior+ecephys.nwb` files
(~0.5 TB total, ~1 GB each). It downloads each one, reduces it to tables and
deletes it, so disk use stays at a few GB. It can resume: re-running it skips
sessions that already finished and retries any that failed.

## Reproduce

```bash
pip install pynwb pandas pyarrow requests matplotlib reportlab
python dandi_export/export_000409.py dandi_export/output_000409 --tmp /scratch --workers 4
python dandi_export/make_report_000409.py dandi_export/output_000409 dandi_export/DANDI_000409_report.pdf
```

`output_000409/tables/*.csv` is committed where GitHub's size limits allow.
The large per-session and Parquet outputs are gitignored.

## Region labels

IBL stores each channel's location as a full Allen structure *name* with
punctuation removed. `region` holds the Allen acronym, matched after
normalising punctuation against `allen_structures.csv`, a snapshot of the
Allen Mouse Brain Atlas ontology. `region_name` holds IBL's original name.
The literature regions are **ZI** (zona incerta) and **LHA** (lateral
hypothalamic area). ZI's subdivisions **FF** (fields of Forel) and **A13** are
kept as separate labels. Allen **LH** is the lateral *habenula*.

## Files

### `tables/sessions.csv`
`session_id` (`<subject>_<first 8 chars of session uuid>`), `session_uuid`
(IBL eid), `asset_path`, `subject_id`, `lab`, `institution`, `sex`, `age_days`
(at recording), `weight_kg`, `session_start_time`, `protocol`, `n_probes`,
`n_trials`, `n_units`, `n_good_units`, `task_duration_s`, `regions`.

### `tables/units.csv`: one row per unit
| column | meaning |
|---|---|
| `session_id`, `unit_id` | key; `unit_id` is the row index within the session's units table |
| `unit_name`, `cluster_uuid`, `probe` | IBL identifiers (`cluster_uuid` works with the ONE API) |
| `region`, `region_name` | Allen acronym and full name at the unit's max-amplitude electrode |
| `ccf_x`, `ccf_y`, `ccf_z` | CCF coordinates (µm) of that electrode |
| `distance_from_probe_tip_um` | depth along the probe |
| `kilosort2_label` | Kilosort's `good` / `mua` label |
| `ibl_quality_score`, `good` | fraction of the 3 IBL metrics passed; `good` = 1.0 (the IBL standard inclusion rule) |
| `peak_to_trough_ms` | trough-to-peak of the mean extracellular waveform (−1 in the source → blank); not intracellular AP half-width |
| `median_amplitude_uV`, `presence_ratio`, `isi_violations_ratio`, `spike_count` | quality metrics from IBL |
| `firing_rate_hz` | IBL's whole-recording mean rate |
| `task_rate_hz` | rate from first trial start to last trial end |
| `prestim_rate_hz` | mean rate −0.4…−0.1 s before stimulus onset, while the mouse holds the wheel still. This is the closest analogue to a spontaneous/baseline rate. |
| `stim_rate_hz` | mean rate 0…0.25 s after stimulus onset |
| `subject_id` | mouse |

### `tables/trials.csv`: one row per trial
Columns from the NWB trials table: `start_time`, `stop_time`,
`quiescence_period`, `gabor_stimulus_onset_time`, `auditory_cue_time`,
`wheel_movement_onset_time`, `choice_registration_time`, `feedback_time`,
`gabor_stimulus_offset_time`, `gabor_stimulus_contrast` (%),
`gabor_stimulus_side` (left/right), `mouse_wheel_choice`
(counter_clockwise = correct for a right stimulus, clockwise = correct for a
left stimulus, or no-go), `is_mouse_rewarded`, `reward_volume_uL`,
`probability_left` (block prior: 0.5, 0.2, 0.8), `block_type`, `block_index`.

### `tables/region_summary.csv`
Per region (good units only): `n_units`, `n_sessions`, `n_mice`,
mean/SD/median `firing_rate`, mean/median `prestim_rate`, mean `stim_rate`,
median `peak_to_trough_ms`.

### `trial_unit_counts.parquet`
`session_id`, `trial_id`, `unit_id`, and spike counts in four windows:
`count_prestim` (−0.4…−0.1 s before stimulus), `count_stim` (0…0.25 s after
stimulus), `count_premove` (−0.25…0 s before wheel-movement onset) and
`count_feedback` (0…0.5 s after feedback).
