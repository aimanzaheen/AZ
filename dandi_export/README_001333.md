# DANDI:001333 export (PESD, simulated Parkinson's signals)

Plain-table export of
[DANDI:001333 v0.250327.2220](https://doi.org/10.48324/dandi.001333/0.250327.2220),
the Parkinson's Electrophysiological Signal Dataset (Biswas 2025; arXiv:2407.17756).

**This dataset is simulated.** Every file comes from the Fleming et al. (2020)
cortico-basal-ganglia network model run in NEURON, so none of it is a recording.
The "subjects" are simulation conditions (healthy vs parkinsonian network ×
signal type). The species, age and sex fields in the files are placeholders.

**Duplicates.** Only 33 of the 52 files are unique. The 10 healthy beta-ARV
files are byte-identical to one another, and so are the 10 healthy LFP files
plus `healthy-simulated-data`. The healthy condition is therefore a single
simulation run. Filter to `unique == True` before running any statistics.

## Reproduce

```bash
dandi download DANDI:001333/0.250327.2220
python dandi_export/export_001333.py 001333 dandi_export/output_001333
python dandi_export/make_report_001333.py dandi_export/output_001333 dandi_export/DANDI_001333_report.pdf
```

## Files

### `tables/sessions.csv`: one row per NWB file
| column | meaning |
|---|---|
| `sample_id` | `<group>_<signal>_ses-<n>` |
| `file`, `nwb_series` | source NWB path and ElectricalSeries name |
| `group` | `healthy` / `parkinsonian` |
| `signal` | `lfp` (STN LFP, 2 kHz) or `beta_arv` (beta-band average rectified value, 50 Hz) |
| `n_samples`, `fs_hz`, `t_start_s`, `t_end_s`, `duration_s` | timing |
| `md5`, `duplicate_of`, `unique` | duplicate detection on the signal values |
| `mean_v`, `sd_v`, `rms_v`, `min_v`, `max_v` | amplitude statistics (V) |
| `beta_power_v2` | LFP only: Welch PSD integrated over 13–30 Hz |
| `total_power_1_100_v2`, `relative_beta_power` | LFP only: 1–100 Hz power and beta / total |
| `peak_freq_hz`, `peak_psd_v2_per_hz` | LFP only: spectral peak in 5–45 Hz |

### `tables/psd.csv`
Welch PSD (2 s Hann segments, 0.5 Hz resolution) of every LFP file from 0 to
100 Hz: `sample_id`, `group`, `unique`, `freq_hz`, `psd_v2_per_hz`.

### `signals/<sample_id>.csv`
The raw signal: `time_s`, `voltage_v`. These files are gitignored (~66 MB);
re-run the exporter to regenerate them.
