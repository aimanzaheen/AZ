# Dandi Data sets

One folder per Dandiset. Generated by `dandi_export/build_deliverables.py` (re-run it to refresh).
`index.csv` lists every dataset with its version, size, report and contents.

Each `DANDI_<id>/` contains:

| Path | What it is | Source |
|---|---|---|
| `DANDI_<id>_report.pdf` | Neutral report: published metadata quoted verbatim, file contents, all regions summarised identically, column descriptions | built by this export |
| `metadata/dandiset.yaml`, `dandiset.json` | The Dandiset's published metadata, as served by the DANDI API | DANDI Archive |
| `metadata/assets_manifest.csv` | Every file in the Dandiset: path, size, asset id, download URL | DANDI Archive |
| `metadata/nwb_file_metadata.json`, `nwb_descriptions.csv` | File-level NWB fields and every column's description, from one NWB file | NWB files |
| `exported_tables/*.csv` | Tables extracted from the NWB files (sessions, units, trials, region summary, ...) | built by this export |
| `original_files/` | Non-NWB files the authors published elsewhere and link from the Dandiset metadata | authors |

## Original (non-NWB) files

None of these Dandisets contains CSV or other tabular files. All data is in NWB,
so the tables in `exported_tables/` are read directly from the NWB files. The
authors' own non-NWB material, where they link to it:

- **000021 / 000022** (Allen Visual Coding – Neuropixels): `original_files/allen_ecephys_cache/`
  holds the Allen Brain Observatory's own tables (`sessions.csv`, `probes.csv`, `channels.csv`,
  `units.csv`, the two `*_analysis_metrics.csv`, `manifest.json`) from
  `s3://allen-brain-observatory/visual-coding-neuropixels/ecephys-cache/`. Unit regions are
  in `channels.csv` (`ecephys_structure_acronym`, Allen CCF acronyms); join `units.ecephys_channel_id`
  → `channels.id`. 000022's folder points to the same files.
- **000409** (IBL Brain Wide Map): the data-release document linked from the Dandiset
  (figshare 21400815).
- **001326** (Kauvar, Richman, Liu et al.): `analysis.py`, the analysis code on Zenodo
  (record 14876694) that the Dandiset lists as a supplement.
- Other Dandisets link only to papers (see `relatedResource` in `metadata/dandiset.yaml`).
